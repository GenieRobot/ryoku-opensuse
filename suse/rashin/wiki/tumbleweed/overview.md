# Ryoku Wiki on openSUSE Tumbleweed

This offline library keeps all eight Ryoku 1.0 guides, with an openSUSE
Tumbleweed introduction and Linux basics. Each page identifies its pinned
upstream source. The original edition remains available as a reference.

Start with [Linux basics](linux-basics.md), then the [desktop tour](desktop.md).
The [Hyprland Lua](hyprland-lua.md), [Niri KDL](niri-kdl.md),
[Quickshell QML](quickshell-qml.md), [upstream Go tools](go-tools.md) and
[Rashin](rashin.md) guides describe their respective upstream components.
Native shell shortcuts and harness support depend on the installed providers;
Niri remains a retained phased edition rather than the current Tumbleweed default.

## This assistant workspace

Ask is a separate read-only lane. Agent and Chat keep independent conversations.
A handoff always requires your action. A saved unavailable model stays saved;
choose another model explicitly when needed. External providers use the endpoint
and credential you configured. Credentials and conversation data stay private.

The browser provides provider/model settings, conversations, reviewed Fix
investigations and local usage controls. Local deterministic retrieval works
without a provider account or network. Index a guide to make its verified text
available to Ask and the other configured lanes. Guide indexing preserves other
uploaded documents and requires explicit confirmation before replacing a document
with the same name. Reading or indexing a guide executes none of its commands.

## Configuration and recovery

Use the configuration owner and typed Ryoku operation for desktop changes.
A repair plan still needs its own authorization and verified linked recovery;
conversation approval alone does not authorize a system mutation. Root snapshots
and matching private configuration/profile state belong to the same recovery
generation. Preserve unrelated files and retain offline recovery inputs.

Rashin is optional at login. Starting it now, enabling login startup, lingering,
stopping it and removing it are separate choices.
